> An R&D project focused on accelerating drug discovery, automating pharmaceutical documentation, and building tailored AI applications.

---

### 💡 About Us

- 🧬 **Bio & Pharma AI**: Developing AlphaFold-based drug discovery platforms and RAG-driven automated review pipelines for pharma documents (CTD, package inserts, etc.).
- ⚡ **Automated Pipelines**: Researching self-improving pipeline frameworks and intelligent research assistant AI systems.
- 📱 **Cross-Platform & Web**: Building user-centric mobile and web applications powered by Flutter, Kotlin, and TypeScript.

### 🚀 Key Projects

#### 🧬 Bio & Healthcare AI
- **[alphafold-drug-platform](https://github.com/danjjak-ai/alphafold-drug-platform)** — AlphaFold-based platform for drug discovery and protein structure analysis
- **[Ctd2Doc](https://github.com/danjjak-ai/Ctd2Doc)** — Self-improving pipeline framework for automated CTD documentation
- **[MedAutoRAG](https://github.com/danjjak-ai/MedAutoRAG)** — Domain-tailored RAG retrieval system for medical and pharmaceutical data
- **[PMDA-Data](https://github.com/danjjak-ai/PMDA-Data)** — Data processing pipeline for Japanese PMDA drug records and package inserts

- **[DocRev](https://github.com/danjjak-ai/DocRev)** — AI-powered document review and inspection system
- **[researchAssistance](https://github.com/danjjak-ai/researchAssistance)** — AI agent supporting research projects and literature surveys
- **[CoWrite-IF-AI](https://github.com/danjjak-ai/CoWrite-IF-AI)** / **[CoWriter-AI](https://github.com/danjjak-ai/CoWriter-AI)** — Collaborative AI writing and content generation tools
- **[PolisayAI](https://github.com/danjjak-ai/PolisayAI)** — Personalized AI web automation service

#### 📱 Mobile & Web Apps
- **[Danjjak-AI-flutter](https://github.com/danjjak-ai/Danjjak-AI-flutter)** — Flutter-based cross-platform mobile application
- **[danjjak](https://github.com/danjjak-ai/danjjak)** — Native Android application written in Kotlin
