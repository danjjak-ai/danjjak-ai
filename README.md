- 🧬 **Bio & Pharma AI**: AlphaFold 기반 신약 개발 플랫폼 및 RAG 기반 제약/의약 문서(CTD, 添付文書 등) 자동 리뷰 파이프라인 구축

- 📱 **Cross-Platform & Web**: Flutter, Kotlin, TypeScript 기반의 사용자 친화적 모바일 및 웹 서비스 개발
